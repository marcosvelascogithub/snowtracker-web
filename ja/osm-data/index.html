出典

次の全世界のコース抽出データから作成： OpenSnowMap （planet_pistes.osm.gz）。データはOpenStreetMapのものです。線は簡略化し、アプリで使わないタグは削除しています。アプリのバージョンごとに更新します。

形式

pistes-index.json： extract は抽出日。 zones の各要素は [最小緯度, 最小経度, 最大緯度, 最大経度, オフセット, 長さ]：ゾーンを囲む矩形と、pistes.bin内のブロックの位置（バイト単位）。

pistes.bin： ゾーンのブロックを順に並べたもの。各ブロックはxzで圧縮したGeoJSON（FeatureCollection 、 LineString）です。各コースには piste:type と、あれば piste:difficulty と name （その name 、なければ piste:name）があり、各リフトには aerialwayがあります。値はOpenStreetMapのものです。

resorts.json： extract は抽出日。 resorts の各要素は [名前, name:es, name:en, name:de, name:fr, name:it, name:nl, name:pl, name:cs, name:sv, name:da, name:ru, name:ja, name:pt, 同じ順序の13言語での国名, 最小緯度, 最小経度, 最大緯度, 最大経度]：OpenStreetMapでのスキー場の名前、あればアプリの各言語での名前、コースとリフトを囲む矩形。
